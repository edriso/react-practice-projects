# Backroads

Travel landing page built with React and Vite. Requires Node.js 22.

- `npm ci` installs the locked dependencies.
- `npm start` starts development.
- `npm run build` builds the site into `build/`.
- `npm run preview` serves the production build locally.

The unmaintained Create React App toolchain was replaced with Vite to remove vulnerable build dependencies. The React components and public assets are preserved.
